# Personal Portfolio

This is a personal portfolio website featuring a modern, responsive design and a built-in contact form. 

## Features
- **Responsive Design**: Looks great on desktop and mobile devices.
- **Custom Backend**: A lightweight Node.js server (`server.mjs`) serves the static files and handles API requests.
- **Contact Form**: Built-in contact form that saves messages locally to a `messages.json` file.

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
- Node.js (for the backend server)

## How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/NAMPELLYGNYANENDRACHARY/personal-portfolio.git
   cd personal-portfolio
   ```

2. **Start the server**:
   Make sure you have Node.js installed, then run:
   ```bash
   node server.mjs
   ```

3. **View the site**:
   Open your browser and navigate to [http://localhost:5500](http://localhost:5500).

## Contact Form Data
Any messages submitted through the contact form on the live site will be saved to a `messages.json` file in the root directory.
